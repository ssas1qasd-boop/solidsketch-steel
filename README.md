# SolidSketch Steel

A native Android app for steel detailing (Kotlin + Jetpack Compose, OpenGL ES, C++ core over JNI). It is ported from the SolidSketch web build v69 and kept separate from the main native port until the two are merged.

The plan and the working rules are in `CLAUDE.md`. Progress is in `docs/steel/PROGRESS.md`.

The web reference (`reference/solidsketch_v69.html`, about 20 MB) is kept out of git.
